# Heart Islands · 心之群岛

与星灵旅伴 Lovera 一起穿越七座心之群岛，在十四次选择中拼出真实的关系画像。

## 在线体验

[打开 Heart Islands](https://heart-islands-lovera.tutanglien5.chatgpt.site)

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev
```

在 `.env.local` 中填写服务端 `DEEPSEEK_API_KEY`。密钥不会进入前端构建，也不应提交到 GitHub。

## 生产构建

```bash
npm run build
```

项目包含完整的七章故事、十四道关系探索题、Lovera 对话、测算结果、背景图片、配音、音乐与章节转场视频，并已适配手机端操作。
